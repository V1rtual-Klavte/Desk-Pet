### 小实现

1. **静默了解链**：判定「了解还薄」→ 截图（看见项目、结构）→ 读手边文件 → 开子代理（辅助模型 `tools=[]`）静默整理 → 进了解层（带来源，不写用户事实）
2. **画像 · 话题偏好**（新增维度）：记录他爱聊哪些主题与大致占比；主动选材按占比加权，**并留一小份纯随机——不然就收敛了**。现有画像是 `rhythm/apps/focus/activity` 四组、基于窗口观察（不存标题与正文），话题维度属从对话派生的新口径（见[行为画像](../../docs/current/behavior.md)）
3. **主动选材**：内容池按画像取材（甜品 / 职业…）；内容自足、不绑回应；去重记账不反复安利
4. **变量池与消费**：好感度（刻度见对账 4）；`unansweredCount`（她主动一次 → 到他下一次开口前无回应 +1；他一开口归零；「看到就行」类不计；≥2 → 次日降档，**但不停**）；system `hour / dayOfWeek / isNightTime`。消费以提示词分档为主（值进请求视图 ＋ 行为进阶段），代码级只做跨档迁移机会；**不接采样 temperature**
5. **主动链（扫描器）**：确定性单一调度链（心跳 / 窗口事件 → 机会 → 指纹去重、档位 → 规划 → 表达 → 回执）；规划子运行与表达均 `tools=[]`；台词归聊天模型，子代理只做「台词之前」
6. **锚 → 跟进**：对话里立锚（如「周六放纵日」）→ 机会预筛 → 规划子运行评估 → 落任务队列 → 到期成为候选（前篇拍 17 立锚，本场兑现）
7. **拟人化实现**（分条气泡 / 打字节奏 / 正在输入 / 回合分流 / 标记协议 / 受限沉默）：见《[拟人化运行时契约](../../docs/plans/active/拟人化运行时契约.md)》——已批，待实施
8. **记忆写入触发**：用户亲口信息 → 写；她自己的话与主动消息 → 不写；观察类了解带来源，不冒充用户事实
9. **图片消息**：对话支持用户发图，她看得见并能自然回应（本场「大餐返图 → 云吃」的前提）

### 对账（理想 vs 现状，待一并裁决）

1. **每日发话量**：现状「每日成功发话最多 1 条」；理想一天可以多条（本场一天已有：放纵日问候、跑后关怀、Java 投喂；前篇拍 19 一晚也发了 3 条）
2. **连续未回复**：现状「2 次抑制分享 / 好奇 / 节拍、4 次全抑制到新输入」；理想＝**降档不停**——少说、更轻，但不说死
3. **静默时段**：现状「全局静默 22–09」；理想里晚安节奏有花活（如 22:40 的晚安），口径需要统一
4. **好感度刻度**：前篇 0–10；本场「30」——升 0–100 还是另制，待拍板；D 档随刻度一起重划

### 本场补充的规矩（2026-10-03）

1. **条数不固定**：一条、两条、三条都可能，按情境来——不搞每次齐刷刷的三连排比（「整的跟写诗一样」）
2. **他在玩 / 忙的时段**：主动只放自足内容——不碰他正在做的事、不问进度、不催；间隔拉开，气氛留给他
