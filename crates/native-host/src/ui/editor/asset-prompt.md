我要制作一套可叠加的五层场景 PNG 素材，共 L1-L5 五层。

这是“视差分层素材”任务，不是让你每一层都生成一张完整场景。

【全局规则】

1. 所有图层的画布尺寸、视角、透视、构图基准必须完全一致，可以直接原位叠加。

2. 所有图层保持统一：
- 画风
- 色调
- 时间
- 季节
- 光照方向
- 透视关系
- 材质表现

3. 一个元素只能属于一个图层。
绝对禁止不同图层重复出现同一个环境元素。

4. 已经在低层出现的元素，高层禁止重新生成。
例如：
L1 已经有远处楼群，
L2 就不能再次画远处楼群。

5. 每次只生成我当前指定的一个图层。
不要一次把 L1-L5 全部生成。

6. 我没有明确要求修改的东西，不要擅自改变：
- 风格
- 材质
- 色彩
- 构图
- 人物设计
- 光照

7. 除 L1 外，其余图层原则上全部使用真正透明背景 PNG。

8. 不要使用：
- 黑色背景
- 白色背景
- 棋盘格背景
来假装透明。

必须是真实 Alpha 透明。

9. 不要为了丰富画面擅自添加额外内容。

10. 所有图层应该适合分别进行：
- 轻微平移
- 缩放
- 透明度变化
- 动画
以产生视差和灵动效果。

11. 每生成一层时，都先思考：
“这个元素应该属于哪一层？”
如果不属于当前层，就不要画。

12. 不要把当前图层理解成一张完整插画。
它只是完整场景中的一个独立素材层。


==================================================
L1 —— 最底层 / 最远背景
==================================================

作用：
负责整个场景最远处的空间和基础色调。

可以包含：

- 天空
- 云层
- 雾
- 地平线
- 最远处山体
- 最远城市轮廓
- 极远处建筑色块
- 极远处雪地、海面、树林等大色块

要求：

- L1 是唯一可以作为完整不透明底图的图层。
- 细节必须明显少于其他层。
- 远处元素应该低对比度、低细节、带空气透视。

绝对不要出现：

- 近处道路
- 明显的人行道
- 近处树木
- 电线杆
- 路灯
- 栏杆
- 花坛
- 店铺门面
- 近处建筑立面
- 人物
- 飘雪
- 光斑
- 光束
- 粒子

核心原则：

“只画肉眼认为在很远处的东西。”


==================================================
L2 —— 人物后方的中景 / 近景环境
==================================================

位置：

L1 上方
L3 人物下方

作用：

负责人物身后的环境实体，
也是主要的视差环境层。

可以包含：

- 道路
- 人行道
- 路缘
- 雪堆
- 低矮灌木
- 花坛
- 栏杆
- 路灯
- 电线杆
- 树木
- 墙体
- 公交站
- 店铺局部
- 靠近镜头的建筑局部
- 其他人物后面的实体

要求：

- 必须透明 PNG。
- 只画中景和近景。
- 中央人物所在区域尽量留出空间。
- 元素不要太密集。
- 要方便和 L1 产生明显视差。

绝对禁止：

- 天空
- L1 已有的远处城市轮廓
- L1 已有的山体
- L1 已有的远景建筑
- 重新画完整背景
- 人物
- 飘雪
- 光线特效

核心原则：

“只画会处在人物后面、但明显比 L1 更靠近镜头的实体。”


==================================================
L3 —— 人物主体层
==================================================

作用：

角色本体。

要求：

- 真实透明 PNG。
- 只包含人物。
- 人物尺寸和位置必须和整套场景匹配。

如果人物设计已经确定，必须严格保持：

- 脸型
- 五官
- 眼睛
- 发型
- 发量
- 服装
- 围巾
- 配色
- 材质
- 线条
- 阴影风格
- 整体画风

绝对不要添加：

- 背景
- 地面
- 树木
- 栏杆
- 光斑
- 飘雪
- 环境粒子
- 额外装饰

人物固定穿戴物，例如：

- 围巾
- 帽子
- 耳机
- 发饰

属于 L3。

核心原则：

“L3 只负责人物本身。”


==================================================
L4 —— 光线 / 氛围滤镜层
==================================================

位置：

L3 人物上方
L5 粒子下方

作用：

非常轻微地统一人物和环境氛围。

只允许：

- 极淡冷白光
- 冬日白光
- 很弱的局部光线
- 极薄空气雾光
- 微弱边缘光
- 非常轻的色温滤镜

要求：

- 真实透明 PNG。
- 整体必须非常克制。
- 更像后期滤镜，而不是特效素材。

默认：

光效仅占画面的约 5%-15%。

其余区域完全透明。

例如：

“右上角一点点冬日白光”

就只能在右上角存在一小块非常淡的光。


绝对不要：

- 巨大光柱
- 大面积糊光
- 强烈 Bloom
- 光球
- 光点
- Bokeh
- 雪花
- 灰尘
- 粒子
- 实体物体
- 黑色底

核心原则：

“如果第一眼明显注意到光效，那就太强了。”


==================================================
L5 —— 最上层动态粒子
==================================================

位置：

整套场景最上方。

作用：

制作可独立动画的前景粒子。

根据场景可以是：

- 飘雪
- 雨滴
- 落叶
- 花瓣
- 灰尘
- 小颗粒

要求：

- 必须真实透明 PNG。
- 全画面自然随机分布。
- 中心区域也要有少量粒子。
- 不能全部集中在四周。
- 但整体一定要稀疏。

默认建议：

70%-90% 的画面保持完全透明。

粒子尺寸：

以非常小的粒子为主。

允许极少数：

- 稍大的近景粒子
- 略带运动模糊的粒子

但数量必须极少。


以飘雪为例：

需要：

- 少量
- 小尺寸
- 自然随机
- 中间也有一点
- 方向略有变化

不要：

- 巨大雪团
- 密集暴雪
- 大片模糊白块
- 发光
- 光晕
- 黑色阴影
- Bokeh
- 大量虚焦雪球
- 背景
- 地面
- 任何实体

核心原则：

“它是动画素材，不是雪景插画。”


==================================================
输出时的额外约束
==================================================

每次我说：

“生成 Lx”

你必须：

1. 只生成 Lx。
2. 检查其他层应该出现的内容并主动排除。
3. 不重复之前层中的元素。
4. 不自行补全完整场景。
5. 优先保证这一层可以和其他层直接叠加使用。
