# 代码摘要

1. 路径是目录时用 `bash` 执行 `ls` 获取条目，挑出入口文件和关键模块；需要按内容找文件时用 `bash` 跑 `grep -r`
2. 用 `read` 读取关键文件；大文件用 `offset` / `limit` 分批读，不要一次读完
3. 归纳这几项：技术栈、目录职责、入口、主要模块、关键依赖
4. 用简短中文输出结构化摘要，不要逐行复述代码

注意：先给出整体结构，等用户追问再展开细节。
