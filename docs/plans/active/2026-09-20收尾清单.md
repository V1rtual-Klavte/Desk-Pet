## 1. 本期执行：表情 / 动画 / 音效收尾

边界已于 2026-09-20 按源码核实并确认。**目标**：完全移除表情系统、角色帧动画系统，以及角色级与 Profile 级的音效映射；只保留系统级音效。

### 1.1 前提事实（已按源码核实）

- 表情链从未接通：`EXPR_MAP` 恒为空对象（`buildExprMap()` 零调用者），`expressionCommands` 在模块求值时展开为空数组，`/smile`、`/sleep` 等按普通文本透传给模型。
- `deskpet-expression` 与 `deskpet-sound` 各只有 emit、零监听；`StreamView.vue` 无表情渲染层，也没有 `setExpression` 出口。
- [`command-handler.ts`](../../../src/services/command-handler.ts) 与 [`animation.ts`](../../../src/services/animation.ts) 全仓零引用。
- 角色帧动画素材（两张 Profile 各 109 个 PNG）当前没有任何显示消费者；立绘走 `materials/L2/body.png`。
- 音效全部为 Web Audio 实时合成，仓库无音频文件；系统级 8 个事件定义在 [`audio/registry.ts`](../../../src/services/audio/registry.ts)。
- `ProfileSound`（`profile.yaml` 的 `sound:`）读入后零消费者，真正生效的是 CONFIG `appearance.soundAssignments`。
