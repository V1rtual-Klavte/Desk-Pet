# 记忆检索底座 P0–P4 执行契约（2026-10-18）

状态：P0–P4 与 P5-A 已落地并验证（2026-10-18）；P5-B 待实施。P5-A 的基线结果与剩余项记录在 [未完成工作与已知缺口](未完成工作与已知缺口.md) §3，本文不复制数字。
入口：根 [AGENTS](../../../AGENTS.md)；当前行为见 [memory](../../current/memory.md)、[database](../../current/database.md)。

## 目标

把记忆管线从“词面覆盖率 + top-50 + 单次阅读”升级为“可枚举的结构化词面检索”：

1. 入库不丢长消息尾部、失败不假装完成、合并不丢事件时间。
2. 索引带上下文、绝对事件日期、词表/IDF，检索能纠拼写、按意图扫描。
3. 召回不再让阅读器漏引直接变成主答漏证据；计数走批量枚举。
4. 评测能分开看“候选找全 / 最终包没丢 / 给定证据答对”，六题不再做决策。

非目标：本轮不引入向量检索、不默认打开 LLM rerank、不改 CONFIG 出厂默认、不推送远端。

## 关键决策

- 会话索引是可重建缓存：schema v5 直接重建 entries/fts，保留 suppression/fence/meta。
- 水位唯一推进点在提交事务；`job_checkpoint` 不再写 `memory_watermarks`。
- episode 不参与库内合并；独立经历不能被概括成一条。
- 重排不是第一杠杆：默认 off，bench off；先修候选召回与排序。
- 金标歧义不追：照片年份计数、教育过度推断保持“有据的下限/有限推断”。
