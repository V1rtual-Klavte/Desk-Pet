## 保留的产品待办

表情动画、声音分级和旧命令链此前未纳入运行时前置。本次仅订正文档，后续单独确认产品范围：

- 表情命令的 EXPR_MAP 尚未在注册前构建，旧 `/smile` 等不是可用命令。
- deskpet-expression 的 UI 消费、旧 animation/command-handler 接线需复核，不能把解析出 emotion 当作视觉效果验收。
- 未回复数分级提示音、reply 双播，以及 Card 切换后旧 effects 返回值的播放隔离需一并检查。

新增修复应同步受影响 current 契约与 Contract/Scene，完成后集中验证。历史记录中的“本轮不做”只说明原范围，不自动成为未来会话授权或永久禁令。
