### 3.2 尚未完成的验收口径

- **权威质量对照（主口径）**：LongMemEval oracle（常规回归层，官方判分移植）、MemoryBank cn（中文对照）、LoCoMo（对外可比，词面 F1、免 judge）按 [memory-bench README](../../../test/memory-bench/README.md) §8 的分层节奏在本机运行；报告与 hypotheses 是质量证据。门禁保持现状：CI／`test:release` 不跑评测集（最多冒烟级自检），完整评测集在本机跑通后再发布；允许子集与偏差的口径、许可与官方判分差异按该 README 执行，不用自建 80 题替代权威对照结论。
- **兜底冒烟与治理语义回归（自建 80 题）**：80个中文标注用例，称呼／稳定偏好、经历／时效、纠正、遗忘各20；回答分别评估称呼、偏好、经历时效、纠正、遗忘五项能力。无记忆／纯本地／always／adaptive／gold五策略各至少3trial，always仅供评测。每cell独立SQLite与store generation、相同规范化fixture指纹、关闭模型工具及自动收集／dreaming、配对随机顺序并记录seed；禁止复用上一组库或暖会话。
- **判定门槛**：来源越权、跨scope、未经复核提交、遗忘复活确定性零失败；五项回答正确率分别≥90%，自动提取precision≥95%、recall≥80%。gold需两人独立完整审计；回答／提取由经人工校准且不同于被测模型的judge盲审，或人工盲审，评分绑定dataset与完整采集产物hash；不得失败后临时放宽。
- **重排收益与成本**：每scope候选Recall@50、合并池Recall、选择Precision/Recall、旧事实泄漏、拒答、fallback、额外token与缓存分别报告。按题目聚合3trial后bootstrap95%区间；adaptive默认开启须回答质量不退化、可重复收益且区间下界为正。无收益或几乎总超时维持默认off。召回总延迟按实际配置截止，重排延迟／fallback、首答配对P50/P95与Provider／网络耗时分列；usage缺失为未知，不算零成本。
- **资源与治理整链**：1k／10k冷热、短词、打开／重建／提交／备份／争用、真实IPC与正文取回；10k热路径P95≤500ms。release存储、debug IPC与release UI/IPC分域；产品RSS/CPU、二进制增量、DB/WAL/SHM/候选/报告/备份总磁盘及LLM账分别保留基线。还需>5MiB真实JSONL的列表／打开／来源收集与失败不推进水位、遗忘后重建来源／索引／旧批次／旧备份不复活、任务抢占／取消／重启／租约竞争与持久预算故障矩阵。
- **UI与全平台**：使用§3隔离设施记录真实settings往返与跨窗口revision；Windows原生check/Rust/L2/L3须对应当前提交。修复后重做受影响快层与完整严格L4，更新Contract真实覆盖与哈希；发布时执行现有test:release门禁。命令和报告流程见[测试README](../../../test/README.md)，不得以本轮静态review冒充已执行。
