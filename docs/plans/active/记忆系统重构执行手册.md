## P6 最小实施顺序

1. 定义 SQLite schema、迁移与导入/导出，并保留 Markdown 的人工可读投影边界。
2. 建立候选记录、来源/版本/置信度、冲突与撤销模型；默认不自动写入。
3. 实现按 scope 和 token 预算受控的 recall，再把只读 projection 接入 Runtime。
4. 设计画像写入确认、纠正/遗忘与 dreaming 的后台调度。
5. 为提取、召回、污染隔离、压缩恢复、冲突和撤销补 Contract/Scene；最后集中执行类型、模块和严格 Live 门禁。
