# 行为观察与画像

行为画像是 `data_root/behavior/` 下独立的派生数据域。它不进入长期记忆、dreaming、记忆召回或用户事实。静默访问设置是观察许可；关闭时 Rust 观察线程停止采样，前端清当前快照并结束画像分段。隐私清除先撤销主动来源对行为画像的引用，再清除画像文件与内存读模型。

## 原生观察

Rust 单一 monitor 线程发出 `window-observed`。采样由原生事件驱动：macOS 注册 NSWorkspace 的前台切换／系统睡眠唤醒／显示器睡眠唤醒／会话切换通知与锁屏、解锁分布式通知，Windows 安装前台窗口 WinEvent 钩子与会话、电源（睡眠唤醒、显示器开关）通知；不再按固定间隔轮询，`general.desktop.pollingIntervalMs` 已退役、运行期无消费者。系统或显示器睡眠、会话恢复先补发一条 `suspended` 边界再发新采样，避免把离开时长当成连续使用。每个有效采样包含 `appId/app/title`、Unix `observedAt`、本代 monotonic `sampleMonoMs`、`monitorGeneration`、单调 `sequence`、系统 idle、锁屏/不可用/挂起/关闭状态及桌宠可见和前台状态。Windows 应用标识只取进程文件名 stem，不保存可执行文件路径；macOS 取 bundle id 与当前应用名，标题只取属于前台进程（窗口 owner PID 匹配）的窗口，否则标题缺失。锁屏和不可用状态不带应用或标题。独立 `get_runtime_activity` 只返回桌宠可见/前台、观察可用/锁屏状态、idle 和采样时间，不返回当前应用身份，空闲资格按需现采。

前端唯一事件入口做形状、代际和序号校验：旧代际、重复和乱序样本丢弃；窗口工具只读这份快照。窗口观察订阅者同步收到原事件，画像写盘在自身串行队列执行，不阻塞主动规则的事件监听。

## 分段、聚合和质量

相同应用的连续观察合并；变化、关闭、锁屏、不可用、暂停（`suspended` 边界）都会截断分段。事件驱动下两次观察的间隔不再代表空窗：没有事件本身就代表前台未变，整段时长回填给上一条观察；只有显式中断状态才切断分段，系统时间回退仍截断。`unobservedMs` 只来自时钟回退截断与采集队列溢出，不再由采样间隔推导。已知边界：显示器常亮、无输入、未锁屏且未进入系统睡眠的时段没有原生事件，仍按「前台未变」回填（显示器睡眠事件把这类时段的上限压到系统配置的显示器睡眠超时；配置为永不睡眠时无界）。跨本地日、小时的时长拆分。系统 idle 超过 5 分钟归入 idle，不计活跃工作。

单日聚合包含 `categoryMs`、本地小时直方图、appId 时长、工作连续段统计、切换数、`coveredMs`、`unobservedMs`、`idleMs` 和桌宠前台使用时间。appId 每日最多记录 64 个；没有标题、正文、标题哈希或截图。滚动 JSONL 分片每片不超过 512 KiB、保留 30 日；daily JSON 保留 180 日；最新四类画像只留内存读模型，可由 daily 重算。

画像提供 `rhythm/apps/focus/activity` 四组近30个日历日画像；另有按最近7个日历日裁剪的 `weekly` activity/focus，供周回顾使用，不以“最近7个有样本的日子”代替一周。`quality.eligibleCollectionMs` 是实际收到采样、正在许可采集的时间与已知采样空窗之和；应用未运行或监控关闭期间没有采样，不计入已观测时间。事件驱动下采样间隔本身不再产生空窗，`unobservedMs` 只来自时钟回退截断与采集队列溢出。没有有效采集时间时质量为 `unavailable`；`coverageRatio = coveredMs / eligibleCollectionMs`，至少 3 个有效观察日且覆盖率≥60%才标为 `reliable`。质量不足时仍可使用当前连续观察支持的 30 分钟工作上下文，但不得据此宣称长期作息、精确工时或成就。

`clearBehavior()` 先停 collector 并等待其队列完成，再删除行为目录并清空内存快照。调用端须先在 SQLite 主动控制事务里失效 behavior 来源的机会、任务、未决尝试与派生缓存，然后调用此清理函数。停止后的迟到事件不写回。

## 有限陪伴表现

presence 只允许 `idle/working/resting`。当前实际采样连续观察到工作或开发上下文 30 分钟后可进入 `working`，不依赖长期画像质量门槛；presence 不设到期租约，由下一条观察（系统 idle、锁屏/挂起/不可用、上下文变化）或观察许可关闭、卡片切换显式释放。`working` 抑制非约定主动发话。`resting` 来自当前观察到的 idle 或媒体上下文，不代表人格或真实休息结论。

`StreamView` 只在桌宠容器执行轻微的两秒呼吸动作，每小时最多两次；减少动态效果设置、隐藏或组件销毁时停止。它不移动窗口、不切换 Profile 或视觉效果模式、不播放音频。顶栏文案通过 Card 的 presence key 读取，并由 titlebar owner/priority 服务管理；释放时只清自己的 owner 状态。

## 静默了解与话题参与

**用途是了解用户本身**——他在做的工作与项目、投入和关注的事、生活与兴趣、常用工具与习惯，积累成对用户的了解层；静默了解不是窗口监控的扩展，窗口与截图只是线索之一，决策时以「要更了解这个人，还缺什么」为准。

`observation`持有独立派生文件`behavior/understanding.json`，不进入长期事实、FTS、dreaming或记忆导出。开启许可后在空闲30分钟、来源新鲜、桌宠不在前台且无主回合时采集；一批链路：截图（不可用则回退当前窗口快照）→ 决策调用（辅助模型只输出 `{targets:[{path,kind,why}]}` 候选，最多3个绝对路径；输入含当前窗口与最近已知了解，用于挑「还缺什么」）→ 宿主逐项校验读取 → 整理调用把读到的目录/文件内容与截图一并整理成「关于这位用户的了解」（只写看得到的事，不做身份/人格/情绪推断，也不写成长期事实）。可读范围是用户主目录内的常见目录，不要求项目标记：除凭据路径、应用数据根与主目录系统目录（macOS `~/Library`、Windows `~/AppData`）外都可读取；目录只回条目名（最多40条，跳过隐藏项与凭据类名），文件限32KB，非普通文件、超限或读取中增长的目标跳过并如实说明。决策解析失败、字段非法或路径非绝对时本批不做文件读取，只保留截图。每小时读取上限是模块常量（dev 可调，不进 UI/CONFIG），用 understanding.json 里的滚动时间戳持久记账，超限的本批跳过决策与读取。截图与文件原文不落盘，辅助模型tools=[]；400输出tokens，决策与整理共用同一条模型通道与共享 token 池，一批计一次 attempt，最短批次间隔跨重启持久，每天最多4批。了解记录带 `targets` 审计字段（本批读取的路径，有界截断），可回看 AI 读了什么；TTL7日。

可信、已提交用户原话按参与来源入队，辅助模型分批提取主题标签与权重；正文只在RAM请求中使用，持久只留标签、权重、哈希来源、时间与Card范围。至少两个独立参与来源后才向主动选材提供主题占比；保留90日／512条上限，单次提及不当作稳定偏好。清除水位与失效来源阻止旧正文被回扫晋升；遗忘记忆的源条目与删除会话会撤销关联主题资格。

停止、前台抢占、会话／Card或来源变化会取消旧代际；预算返回与请求前再次核对来源，原生CANCELLED终止整批；结果返回后再次核对许可与来源。主窗口/e2e是唯一写入owner，设置窗口治理只发送来源ID并等待回执。`/behavior clear`先撤销主动资格、等待采集与写队列结束，再清了解与画像；已清的来源不能迟到回灌。
