记忆系统，没有真正实现。这是现状：
## Memory 机制
### 三层
| 层 | 位置 | 注入 Prompt |
|----|------|:---:|
| 长期记忆 | `memory/MEMORY.md` 结构化注册表（4 系统指针 + N 独立条目） | ❌ 不注入（需 LLM 手动调 search tool） |
| 会话记忆 | `sessions/*.md` 实时写入每轮对话 + CompactionSummary | ✅ CANDY/User 全文 + CompactionSummary 固定拼接 |
| 上下文注入 | `builder.ts` 拼到 System Prompt 底部 | 全量固定，无语义检索 |
### 压缩
| 方式 | 触发 | LLM |
|------|------|:---:|
| 内存截断 | 上下文 ≥ 95% → 保留 40% + 摘要占位 | ❌ |
| 增量压缩 | compactOnHighUsage → 新消息→LLM→CompactionSummary | ✅ low |
| LLM 整理 | 每60min / 2会话结束 → MEMORY.md 去重/过期/合并 | ✅ medium |
| Fork 补充 | 压缩后异步 → 从对话提取新事实→append | ✅ low |
### 检索
- `searchMemory(keyword)` — 关键词匹配+打分，只有 LLM tool 能调用
- 无语义检索、无 RAG、无自动关联注入
- 注入 prompt 的记忆是**固定的**：CANDY.md + User.md + CompactionSummary
