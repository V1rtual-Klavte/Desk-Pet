- **剩余未做项见[未完成工作与已知缺口](../../plans/active/未完成工作与已知缺口.md)**。
- **本轮的口径订正**：方案 §5.1 原有「按逐工具 `executionMode` 调度并行」的描述与上游不符——Harness 只读 run 级 `toolExecution`，不再读逐工具字段，此前 `harness-slot` 写死 `"sequential"`，故「纯读并行」从未生效；改为由 Rust 许可所有者保证互斥后 `toolExecution` 才置 `"parallel"`。方案内已加实施订正注记。
