# 轻量陪伴运行时与统一内核建设方案（2026-09-20 基线）

> **归档说明**：本页于 2026-09-20 归档。A–E 已完成，后续目标 F（长期记忆）与 G（质量与运营）已迁入 [2026-09-20 收尾清单](../../plans/active/未完成工作与已知缺口.md)。以下正文保留当时的方向与依据。

Desk-Pet 保持陪伴模式的低资源与低打扰；助手模式按需获得工具、Skill 和 MCP。Context 决定请求视图，领域 Store 决定事实，Pi 消息列表和 Vue 展示都不成为第二真相源。

## 已完成成果

- **A. 会话与运行时**：事件、队列（现为 lane 持久 inbox）、Plan checkpoint 与来源隔离已落地。[当前契约](../../current/runtime-contract.md)
- **B. 上下文与压缩**：ContextKernel、稳定前缀、完整 round checkpoint 和受限工具原文读取已落地。[当前契约](../../current/runtime-contract.md#请求生命周期)
- **C. 安全与网络**：PermissionKernel、MCP passthrough 终裁、代际授权和 Provider origin/redirect 边界已落地。[当前契约](../../current/runtime-contract.md#pi权限与网络)
- **D. 渐进能力**：Skill 缓存仅保留元数据，工具/MCP 由运行 owner 按需取得，模式切换不破坏在飞回合。
- **E. 运行时内核**：[Pi 方案 §8](../implementation/Pi运行时与工具协议建设方案-2026-09-20基线.md#8-agentharness-迁移运行内核替换) 的 H-1–H-4 已实施并通过 2026-09-18 集中验证（AgentHarness 运行槽、JSONL 会话、原生 inbox/hook/压缩调度，旧队列与压缩调度已删）；协议正文归档于 [AgentHarness 迁移方案基线](../../history/implementation/AgentHarness迁移方案-2026-09-18基线.md)，已知断链与剩余目标（插话双模式 UI、工具策略 PI-2）见 [2026-09-20 收尾清单](../../plans/active/未完成工作与已知缺口.md)。

## 后续目标

- **F. 长期记忆**：SQLite MemoryStore、候选审查、受控 recall、画像更正/遗忘与可撤销写入。
- **G. 质量与运营**：Memory Eval、dreaming 调度、检索质量/成本指标和恢复演练。

不在 F/G 中补建没有消费者的通用 HookBus，也不把候选类名当作必须提前建立的空模块。旧比较、候选设计和完整论证见[历史基线](./轻量陪伴运行时与统一内核建设方案-2026-09-17基线.md)。
