# 变量池优化：RUNTIME_DATA 统一输出区域

> 日期: 2026-07-24 | 状态: 设计定稿
> 变量更新从工具调用降级到 LLM 回复结构化区块，统一处理情绪标签和变量更新

---

## 一、问题与目标

### 当前痛点

LLM 每轮回复需要走两套机制：
- **情绪**: `[emo:key]` 前缀标签 → `stripEmotionTag()` 剥离
- **变量**: `var_write` 工具调用 → tool loop 执行 → 返回 result

多了一轮 tool call 往返（token + 延迟），LLM 忘记调用的概率 ~10-15%。

### 目标

将情绪标签和变量更新合并到一个 **RUNTIME_DATA** 区块，放在 LLM 回复末尾，在 `generateReply()` 中一次性解析、写入、落盘。

### 同步清理

移除所有不再需要的旧实现，**不考虑向后兼容**：
- When 引擎 DSL（tokenizer/parser/AST/evaluator，~220行）
- var_write/var_delete/var_read/var_list 全部 4 个工具（~110行）
- builder.ts 中 VAR_TOOLS 过滤 + 变量操作规则注入逻辑
- 存量数据（Card `# 行为进阶` DSL 表达式 → 改为纯白话文本）

---

## 二、LLM 输出格式

### RUNTIME_DATA 区块

LLM 回复末尾必须附加以下区块：

```
宝宝今天陪你写了好多代码呢，辛苦啦～(´▽`ʃ♡ƪ)

<RUNTIME_DATA>
emotion: happy
亲密度: 86
心情: 开心
</RUNTIME_DATA>
```

### 规则

- **`emotion` 行必填**，值从 Card 情绪标签表选择（happy/chu/shy/idle 等）
- **其他行** = `变量名: 值`，选填，只放本轮有变化的 Card 变量
- 没有变量变化时只写 `emotion` 一行
- 区块会被系统自动剥离，用户不可见
- 不需要 `var_read`/`var_list`——变量池当前值已在 prompt 中展示

## 三、数据流

```
agent-loop                              generateReply()
    │                                         │
    ├─ 调 LLM 得 rawReply ───────────────────→│
    │                                         ├─ parseRuntimeData()
    │                                         │   ├─ 匹配 <RUNTIME_DATA>...</RUNTIME_DATA>
    │                                         │   ├─ 提取 emotion key
    │                                         │   ├─ 提取 varName: value 对
    │                                         │   └─ 剥离区块，返回干净文本
    │                                         ├─ resolveEmotion(emotion) → expression + sound
    │                                         ├─ batchWriteVars(vars) → 校验 + 写入 pool
    │                                         ├─ await savePoolToDisk()
    │                                         └─ trim + 截断
    │                                         │
    ├─ processed = await generateReply(raw) ←─┘
    ├─ effects.push(expression, sound)
    └─ return reply
```

**agent-loop 代码改动量**: `generateReply` 加 `await`，删 `savePoolToDisk()` 调用。两行。

## 四、文件改动详表

### ④-1 删除的文件（2个）

| 文件 | 原因 |
|------|------|
| `src/services/personality/when-engine.ts` | DSL ~220行，全部不再需要 |
| `src/services/tool/local/var.ts` | 4个 var 工具 ~110行，全部不再需要 |

### ④-2 emotion.ts — 改

**删**: `stripEmotionTag()` + `EMO_TAG_RE` 常量

**改**: `formatEmotionForPrompt()` — 输出 RUNTIME_DATA 格式指令替代 `[emo:key]` 格式

```
// 旧
[情绪表达规则]
你的回复开头必须携带一个情绪标签 [emo:key]...

// 新
[回复元数据]
你的回复末尾必须附加一个 RUNTIME_DATA 区块：
<RUNTIME_DATA>
emotion: <标签>
<变量名>: <值>
</RUNTIME_DATA>
- emotion 必填，可选: happy(smile), chu(chu,reply)...
- 其他行为 Card 变量更新，选填，只放本轮有变化的
```

**保留**: `resolveEmotion()`, `parseEmotionMappings()`, `EmotionMapping` 类型

### ④-3 variable-pool.ts — 改

**删**:
- `varRead()`, `varList()`, `varWrite()`, `varDelete()`
- `buildVarReadHandler()`, `buildVarListHandler()`, `buildVarWriteHandler()`, `buildVarDeleteHandler()`
- `inferType()`, `inferAndValidate()` 辅助函数

**改**: `formatPoolForPrompt()` 保留用于变量池展示，但去掉工具提示引用

**新增**: `batchWriteVars(updates: Record<string, string>): { written: string[], errors: string[] }`

按 def.type 做类型转换 + min/max/enum 校验，通过则写入 `pool.card[name]`。

### ④-4 generator.ts — 核心改动

**新增 `parseRuntimeData()`**（同文件内，不导出）：

正则匹配 `<RUNTIME_DATA>...</RUNTIME_DATA>` → 按行解析 `key: value` → 返回 `{ text, runtime: { emotion, vars } }`。

**`generateReply()` 改为 async**：

1. `parseRuntimeData(raw)` → 得干净文本 + emotion + vars
2. `resolveEmotion(runtime.emotion)` → expression + sound
3. `batchWriteVars(runtime.vars)` → 写入 pool
4. `await savePoolToDisk()` → 落盘
5. trim + 截断（不变）

**删除**: `stripEmotionTag` import

### ④-5 builder.ts — 精简

**删**:
- `VAR_TOOLS` 常量
- `decideTools()` 中的 var 工具过滤
- 整段「变量操作规则」条件注入（~20行）
- `evaluateWhenEngine` import + 调用

**改**:
- 工具提示：删掉 var/general 区分，统一一句话
- When 区域：直接贴 Card 的 `whenText` 原文

### ④-6 agent-loop.ts — 微小改动

`generateReply` 加 `await`，删 `savePoolToDisk()` 调用和 import。

### ④-7 types.ts — 改

`whenRules: WhenRule[]` → `whenText: string`，删 `WhenRule` import。

### ④-8 loader.ts — 改

`# 行为进阶` 区块不再 parse 成 `WhenRule[]`，直接存原文到 `whenText`。

### ④-9 personality/index.ts — 改

移除 `when-engine` 全部导出、`varRead/varWrite/varList/varDelete` 导出、`stripEmotionTag` 导出。

### ④-10 init.ts — 改

删除 `registerVarTools()` import 和调用。

### ④-11 AITab.vue — 改

`card.sections.whenRules.length` → 删掉这行（whenText 是字符串，不需要显示规则条数）。

### ④-12 Card 模板文件 — 改

- `_template.md`: `# 情绪表达` → 更新为 RUNTIME_DATA 格式说明；`# 行为进阶` → 删 DSL 语法文档，改为白话描述指引
- `pchan.md` 等实际 Card: `## 规则: xxx` + `when:` + `语气:` → 改为纯白话列表
