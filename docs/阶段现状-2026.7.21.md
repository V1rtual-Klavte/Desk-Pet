```

  → buildPrompt(card全量注入)
  → 单次LLM(非流式) → runToolLoop(安全→执行)
  → generateReply(raw, card) → ReplyResult {text,emotionKey,expression,sound}
  → var_write即时落盘 stages/{cardId}.json
```
