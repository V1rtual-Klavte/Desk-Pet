# 文件整理

1. 用 `bash` 执行 `ls` 列出目标目录的全部条目
2. 按扩展名分组：图片、文档、代码、压缩包、其他
3. **先把归类方案讲给用户听，得到确认再动手**
4. 用 `bash` 创建子目录并移动文件；移动是不可逆操作，逐个目录确认
5. 返回结果摘要：新建了哪些目录、各移动了多少文件

注意：

- 不要移动隐藏文件（以 `.` 开头），也不要碰 `SKILL.md`、配置文件这类运行时数据
- 目标目录里已有同名文件时先停下问用户，不要覆盖
